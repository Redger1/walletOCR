1) CoreTypes
Общие модели и протоколы, без UI, без платформенных зависимостей
Нельзя: UI, OCR, логи, хранилища
Когда: чистые вычисления над моделями


2) PersistenceKit
Работа с данными на устройстве, импорт/экспорт CSV, SwiftData/CoreData
Нельзя: UI, OCR, метрики
Когда: доступ к диску или БД


3) VisionOCRKit
Камера и распорзнавание текста из чека, очередь, отмена, тайминги и тд
Нельзя: Доступ к камере напрямую, UI-экран камеры
Когда: камера, распознавание


4) BudgetEngine
Бизнес логика бюджетов и агрегатов: подсчет трат, остаток и тд + кэш
То, что пользователь сам себе задает, чисто его бюджет на выбранный период
Чистые функции/акторы из BudgetService
Нельзя: Хранить данные самостоятельно, показывать UI
Когда: чистые вычисления над моделями


5) DesignSystem
Общие UI-компоненты и тема, шрифты, цвета
SwiftUI, поддержка Dynamic Type, темная тема
Нельзя: бизнес-логика, OCR, работа с базой
Когда: нужен UI 


6) FeatureFlags
Централизованный доступ к фичефлагам/конфигам
Чтение из локального JSON, InMemory (feature_flags.local.json)
Нельзя: принимать решения за фичи, только отдавать значения
Когда: переключение поведения


7) AnalyticsKit
События и метрики
Нельзя: бизнес-логика, доступ к базе
Когда: метрики


8) LoggingKit
Единый логгер и трассировка шагов
Форматирование, уровни, маркеры перфоманса
Нельзя: Хранить состояние приложения, метрики пользователя
Когда: Логи


9) SyncKit (добавить в конце)
Синхронизация через CloudKit
Стратегия конфликтов, версии записей
Нельзя: Нельзя быть жесткой зависимостью - подключается через флаг
Когда: Синхронизация между устройствами
